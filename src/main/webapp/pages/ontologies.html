Arachnolingua Ontologies

  • Domain Ontology for Arachnid Behavior
  • Project Ontology

Arachnolingua imports terms from these ontologies

NeuroBehavior Ontology
OBO ontology for behavior
NCBI Taxonomy
Taxonomy containing Arachnid taxa and a path from Arachnida to root. This currently uses a generated OWL file in OBO foundry, and will not be current with the counts on the taxonomy page, which are updated nightly.
Spider Biology Ontology
Mostly anatomy of spiders
Information Artifact Ontology
Vocabulary of documents including those containing descriptions of behavior
Relations Ontology
Vocabulary of relations among and between entities and processes
Basic Formal Ontology
Root terms for all OBO ontologies

In addition, several other ontologies (ECO, GO, PATO, CHEBI, UBERON, ENVO, PCO) provide terms available to curators.

RDF source for the current KB

The Arachnolingua knowledge base is available as RDF/XML. It can be downloaded here.
